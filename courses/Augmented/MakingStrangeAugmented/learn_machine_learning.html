Walkthrough: Machine-Learning Logic in the Floating-Skin App

1. Pixels become numbers

A computer image is a grid of numbers. Each pixel has red, green, blue, and alpha values.

128

2. Brightness becomes displacement

The designer maps brightness to geometry: displacement = lerp(minDisplacement, maxDisplacement, brightness).

Black can move inward, white can move outward, and gray can stay close to the captured face.

3. A face model predicts landmarks

FaceMesh predicts landmark points. Those points are not identity by themselves; in this project they are used as a coordinate system for art.

4. Depth adds a point cloud

The live capture page exports both a triangular face mesh and a sampled RGB/depth point cloud. The mesh gives structure; the point cloud gives measured surface evidence.

5. Weights mix visual choices

A simple ML idea is weighted combination: output = weightA × A + weightB × B. Texture mixing and region weighting make this visible.
