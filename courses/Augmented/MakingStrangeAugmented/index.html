Workflow State

State 1 shows only the base face/head mesh choices. Texture, brush, SVG-region, point-cloud, and export controls are hidden until the head choice/shape is finished.

Base Face / Head Mesh

Choose the starting mesh. The MediaPipe face is the original 468-point face surface. The procedural and imported choices remain separate models.

SVG Face Section Selection

Click face sections on the SVG map. Shift-click or normal click toggles sections. The map follows the current 468-point face UVs, so selected regions line up with the face mesh.
No sections selected
“Apply source to selected” paints the chosen pattern/upload only inside selected UV regions and switches to fitted UV mapping so the SVG sections line up. Texture can still appear on eyes, mouth, and nose; the protection controls mainly reduce geometry deformation.

Advanced Head Depth

This affects only the procedural full head. The MediaPipe face and imported student heads keep their authored depth/profile.
Lower values flatten the profile; 1.00 preserves the original depth. The default is now 0.90.
Manual Face / Head Shape
These sliders reshape only the procedural full head. They are separated from texture/pattern work so students can clearly see what the mesh sliders do before moving on.
