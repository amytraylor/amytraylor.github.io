Walkthrough: OpenCV and Face Algorithms

1. Detection, landmarks, and recognition are different

Detection asks where a face is. Landmarks ask where key points are. Recognition asks whose face it is.

This workshop uses landmark tracking and mesh deformation for expressive self-portraiture, not identity recognition.

2. OpenCV and classical computer vision

OpenCV helped make image processing and computer vision tools widely available. Classical approaches used edges, corners, templates, Haar-like features, histograms, and geometry.

3. From handcrafted features to learned features

Older systems depended on human-designed measurements. Newer systems learn useful internal features from many examples.

4. Face landmarks as a coordinate system

In this app, landmarks are scaffolding. They let us map image textures, depth points, and displacement onto a face-shaped surface.

5. Ethics and consent

Face algorithms raise issues of consent, bias, surveillance, and error. A creative classroom project should explicitly distinguish artistic transformation from identification.
