UV Floating Points

Smaller step = denser points. Sampling now uses a uniform UV pixel grid, so point spacing is more even and the design pattern keeps the same relative scale as the 1000×1000 source image.
Brightness is mapped continuously from min to max, so black can go inward and white can go outward at the same time.
Point cloud is rebuilt once in animation-frame batches after a change. The sampler distributes the exact requested point count by 3D surface area. By default the design image wraps cylindrically around the face, so the pattern can reach side/back regions instead of behaving like a flat front projection.
