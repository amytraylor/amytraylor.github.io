Computer Vision, OpenCV, and Face Algorithms

Detection, landmarks, and recognition are different

Face detection asks: “Where is a face?” Face landmark tracking asks: “Where are key points like eyes, lips, and nose?” Face recognition asks: “Whose face is this?”

This workshop uses landmark tracking and mesh deformation for art. It is not an identity-recognition project.

OpenCV and classical computer vision

OpenCV helped make computer vision tools widely available. Classical methods used edges, corners, templates, Haar-like features, histograms, and geometric measurements.

From handcrafted features to learned features

Older systems often depended on handcrafted features. Newer systems learn features from data. A face landmark model learns patterns that help predict point locations across faces, poses, and lighting conditions.

Ethics and consent

Face algorithms have serious social consequences. Teaching this history should include consent, dataset bias, surveillance, error rates, and the difference between expressive self-portrait tools and systems used to identify people.

Connection to this app

The floating-skin app uses a face mesh as a creative coordinate system. Students can transform a face into points, textures, and displaced geometry while discussing what the algorithm is measuring and what it is not.
