<h2>New Media Art Pose</h2>

<p>This interactive work is an ongoing collaboration with Carlos Gabaldon.</p>
<p>Each iteration features Carlos' beautiful graphics and Amy's inventive code. At each installation the work runs through a new set of generative states of interactive graphics always focusing on the dialog between artist and participant in relation to Golan Levin's "<a href="http://www.flong.com/texts/essays/essay_pose/" rel="noopener" target="_blank">media art pose</a>." Made with Processing and the Kinect device.</p>
